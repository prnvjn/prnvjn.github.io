# Pranav Jain’s professional portfolio

Live site: https://prnvjn.github.io/

A responsive, static portfolio built with HTML, CSS, and a small amount of JavaScript. It includes a professional bio, personal value proposition and audience, public projects, the AIML-500 Study Companion as Artifact 1, a machine learning comparative report as Artifact 2, three empty artifact slots, and contact links. The structure follows the supplied Professional Portfolio Artifact Template.

## Edit the site

- `index.html`: bio, value proposition, audience, projects, artifact slots, and contact details.
- `assets/style.css`: layout, colors, responsive behavior, and print styles.
- `assets/main.js`: theme preference, mobile navigation, and navigation highlights.
- `assets/artifact.css`: artifact listing and case study layout.
- `artifacts/aiml500-study-companion.html`: Artifact 1, including evidence and all template sections.
- `artifacts/aiml500-chatbot-configuration.txt`: the supplied bot configuration for reviewers.
- `ARTIFACT_TEMPLATE.md`: the information to include when adding real artifacts.

No build or package installation is required. For a local preview, run `python3 -m http.server 8000` from this folder and visit http://localhost:8000.

GitHub Pages publishes the root of the `main` branch. Commit and push changes to update the site.
