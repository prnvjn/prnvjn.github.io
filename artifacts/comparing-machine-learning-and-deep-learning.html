ARTIFACT 02 / MACHINE LEARNING / COMPARATIVE REPORT

Comparing Machine Learning
and Deep Learning Approaches.

Email spam detection vs autonomous driving perception.

CREATOR
Pranav Jain · sole author
CONTEXT
AIML-500, Machine Learning Workshop 2.3
FORMAT
Written comparative report
EVIDENCE
Submitted workshop report

Introduction

I wrote this report to compare one traditional machine learning application with one deep learning application, and to argue that model selection should follow from the structure of the data rather than from which method is newer.

Artifact Description

My role: sole author. The report examines email spam detection as the traditional machine learning case and autonomous driving perception as the deep learning case. For each, it explains the real-world application, why the approach suits the problem, and why the alternative would be less practical.

Artifact-Specific Value Proposition

This artifact shows my ability to reason about model selection from data characteristics, and to justify a technical choice with tradeoffs rather than defending a preferred tool.

Customization for Audience

Written for engineering teams, technical recruiters, and applied AI collaborators. Specific algorithms and features are named for readers who would notice hand-waving, while the reasoning stays plain enough for a skim.

Reflection

The strongest justification for one approach is often the argument against the other, so writing both directions forced a clearer position. My first draft called the alternative approach unsuitable, and the honest version is that it is less practical, for reasons like data volume, compute, retraining cost, and loss of interpretability.

Feedback and Revisions

The rubric weighted strong justification, so I added reasoning against each alternative rather than only the case for the chosen method, and confirmed the two examples sat in genuinely different categories. Instructor comments are not yet available.
